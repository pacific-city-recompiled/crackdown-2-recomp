# 2026-10-30: 120 / 144 fps (Crackdown 2)

Branch `feat/high-fps` (off `feat/camera-sensitivity`, PR #3). PR: pacific-city-recompiled/crackdown-2-recomp#4.

## What changed

- `crackdown2/src/hooks_framerate.cpp`: the float sim step (game update dt of sub_82915C70, step query
  sub_827671D0, 30 Hz frame counter carry) now uses the measured, clamped frame time (`dt * 30`) instead of the
  whole-ms rounded one. At 144 fps a frame is 6.94 ms, so rounding gave a 6/7 ms pattern (each step up to ~15% off,
  judder); at 120 fps 8/9 ms. The 16 integer-ms timer sites still get the carried whole ms, so both add up to real
  time. No setting changes: `fps_cap = 120` / `144` with the default `sim_game_clock` is the whole feature
  (`vsync` stays off by default; `vsync = true` is still the stock 30 fps path).

## Evidence (PC, windowed, muted, isolated data in `out/cd2-portstd-test`, scripted input in the city)

- Frame rate reached (`--frame_log`, last 3000 frames, standing in the city): 60 cap 59.9 fps (p99 17.6 ms);
  120 cap 119.7 (p99 9.3 ms); 144 cap 143.5 (p99 7.9 ms).

  `out/hr144_*`, logs crackdown2_015-021).
